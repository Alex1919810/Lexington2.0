# 角色扮演模块约定

继承根目录 [AGENTS.md](../../AGENTS.md)，模块与功能见 [docs/MODULES.md](../../docs/MODULES.md)；接口约束、实现细节及验证场景见 [docs/DEVELOPMENT_NOTES.md](../../docs/DEVELOPMENT_NOTES.md)。

- 本模块与 backend 平级，保存角色卡、角色映射、提示组装、世界书匹配及角色配置持久化；不依赖 backend、UI、egui，不启动 Codex 或访问其登录信息。
- Codex 进程、会话、协议、审批和权限属于 backend；UI 只编辑草稿及请求保存。角色内容不增加权限。
- 默认资源放在 resource/agents，用户修改放在 config/roleplay.json，保存须保留未知字段与其他角色，原子写入，损坏文件拒绝覆盖。来源和许可不注入模型。
- 使用临时资源验证默认/覆盖优先级、规则与世界书匹配、文件错误及保存保护，不调用真实模型、凭据或用户记录。
- 上下文规划使用明确的字符预算，仅管理本程序附加的角色内容，不伪称已管理 Codex 完整历史或实际 token。核心设定保留，超额可选内容须能检查原因；预览不得推进历史或世界书时效。
- 世界书历史与时效按成功完成的任务提交，中断、失败及忙碌拒绝必须回滚；临时场景与长期记忆分开。用户人设和记忆保存在 roleplay-memory.json，候选仅经明确确认并保存后加载，维护来源不注入模型。
- 历史向量记忆由本模块调用 tools/vector_store，本地推理由 tools/embedding 提供，backend 不直接组织查询。默认启用本地 CPU 模型，已有显式关闭保留；本地不要求地址/Key，不自动回退远程。仅记录成功对话；召回注明历史及非确认事实，与固定记忆分开，按角色/模型隔离并纳入本轮预算，当前明确更正优先于旧记录。预览不得访问数据库、加载模型或请求 Embedding；故障不阻断普通对话。远程 Key 仅从独立环境变量读取，不继承 Codex/OAuth 凭据。
- 人物事件记忆与固定记忆、向量召回分开：成功对话自动提炼并保存，无开关或逐条确认，仅供查看，不注入角色提示。校验原文依据并区分用户陈述/角色扮演；按角色隔离，删除保留指纹防止相同结果立即回写。提炼指令、字段校验和存储策略属于本模块，进程与协议仍属于 backend。
- 新建角色必须附带至少一张可解码的 PNG/GIF，个人卡片与立绘保存到 config/characters；先在隐藏目录完成校验和写入，再发布完整目录，失败不覆盖既有角色或源图。RoleCard::load 先读全局用户覆盖，再读个人角色卡，最后读内置资源；新建不修改内置映射。
