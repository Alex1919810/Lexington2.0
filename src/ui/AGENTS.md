# 界面约定

继承根目录 [AGENTS.md](../../AGENTS.md)；此处仅补充本目录约束。模块职责、接口及详细场景见 [docs/MODULES.md](../../docs/MODULES.md)。

- UI 每 500ms 按配置修改时间/长度检查热加载；用 `Config::read`，失败保留上次有效值，禁止默认回退覆盖。普通设置/审批保持会话；developmentMode 改变，等当前任务结束后清除各项目的活动任务并新建会话；外部模型/API 配置改变后由用户重启会话。资源手动重载。
- 连接参数继承环境，不提供模型/API/Key 表单，也不把凭据复制到用户配置；普通输入只发送裁首尾空白的原文；外部请求单独使用 `handoff::Request::prompt`。等待/忙碌文案使用 Lexington，等待提示固定“Lexington正在思考”。
- 普通窗口 500×500，开发窗口 800×600，立绘容器 450×450；侧栏独立，立绘/对话/输入共享悬停变换。气泡按全文测高、限制最大高度，Area 禁用自动约束以允许溢出；几何和字体参数见模块文档。图片用线性 mipmap；CJK 字体不要再用 FontTweak.scale 放大。
- 设置与中央提醒必须用独立原生 viewport，不能受主窗内 egui::Window 限制；X11 使用 Dock + AlwaysOnTop，不套用桌宠 XShape。映射后延迟一次性激活，提醒须晚于桌宠启动置顶；长内容可滚动、确认按钮固定。show_viewport_immediate 仅主线程使用；Embedded 后端提供 Window 回退，设置用 Foreground。设置操作在 viewport 回调后执行，忙碌禁用重启会话。
- 设置标题栏及正文空白可拖动，按钮/输入/滚动条不得拖窗，正文关闭拖拽滚动。X11/Windows 按原生指针和窗口位置移动，保留按下候选等待 egui 命中结果，不能依赖跨阈值后的 StartDrag 或缓存 outer_rect；其他平台/Wayland 使用 StartDrag。位置仅首次打开初始化，关闭只销毁子 viewport；详细命中与时序规则见模块文档。
- 透明区无 motion 事件，X11 用原生指针轮询发现悬停，失败回退 egui。输入在悬停共同变换后的立绘容器/输入区域、聚焦或生成中显示；离开且失焦后淡出，草稿/错误保留但不强制显示。原生失焦须 surrender_focus；Enter 同时判断 has_focus/lost_focus，启动不主动聚焦。侧栏点击阻止同帧“外部点击关闭”，避免清掉新消息。侧栏动作索引与显示顺序分离，重排时保留动作/动画 ID，并同步依赖按钮坐标的受影响回归。
- egui 0.31 菜单打开时 context_menu 可能返回 None；输入区域须在菜单绘制闭包中取当前矩形加菜单边距，仅打开时提交。回归检查立绘外的“关闭”项连续帧可点击；模拟 UI 事件不能替代原生穿透验证。
- 保持 persist_window=false、禁用 egui 区域缓存、旧 window 字段置空；Storage 分别保存 windowPosition/devWindowPosition，只恢复逻辑位置、不恢复尺寸。X11 保存查原生位置；启动按活动显示器（含负坐标）检查可见立绘至少 24×24，允许透明边距出屏，无效/不可见位置回主屏默认值。
- 截图事件须在 context input 读锁外发 viewport 命令；锁内 Close 会卡住。普通 Color32 导出 PNG 用 to_srgba_unmultiplied()；经过主窗最终桌面预乘转换的帧缓冲读回须用 transparency::screenshot_rgba，不能按普通 Color32 再解码。

## 增量验证

- 角色卡设置保留独立草稿，保存后才写入 config/roleplay.json；当前角色内容变化等任务结束再重建会话，编辑其他角色不重启当前会话。关闭设置或切换编辑对象丢弃未保存草稿；角色领域逻辑放入平级 roleplay，UI 只编辑和提交。
- 用户人设和记忆有独立草稿、保存按钮及 roleplay-memory.json；确认、撤销、停用或删除先改草稿，保存后才应用。上下文页区分实际发送和预览，临时场景在新会话清空；保存用户数据在 viewport 回调后执行，不把候选当成已确认事实。

- 角色切换（包括资源刷新导致的角色回退）立即结束旧 Codex 任务并新建会话；用 codex_character 跟踪启动失败的会话归属，避免失败后切换遗漏重建。同角色的立绘/格式/战损切换保持会话；草稿保留，旧回复和审批清空。测试构造未启动 Client 时不因刷新启动真实模型。

- 涉及中断和轮次的 UI 协议测试先等待模拟服务的首轮流式文本，不能把 UI busy 当作握手或发送完成的证据；握手期间中断会取消尚未发送的消息。

- 按受影响用例名或专项模块筛选，如 `cargo test --locked ui::assets::tests::`；UI 协作范围较大时用 `cargo test --locked ui::tests::`。只补充与改动有关的后端测试。
- 普通/开发窗口输入回归覆盖悬停、聚焦、失焦后草稿/错误恢复和生成中可见；资源侧栏用例统一验证切换、加载和重载保留，避免重复测试。
- 窗口/拖动/穿透改动仅运行对应原生 smoke 模式，环境与指针安全要求见 `scripts/AGENTS.md`；模拟 egui 事件不能替代原生验证。

- 天气仅手动/自动打卡成功或主动搜索/查看时请求，平时不轮询/预取；异步回复按城市、请求 ID、打卡起点/日期校验，取消/换城/跨日丢弃，不能覆盖生成中的聊天或其他消息，也不能改变打卡成功状态。天气设置在 viewport 回调后执行保存/搜索。

- 连接或任务错误不能替换 TextEdit：在其下方限高滚动展示，保留焦点和草稿以继续输入；输入面板按共同变换后的完整尺寸限制在 viewport 内，避免错误展开或悬停缩放导致出屏。回归需在已输入若干字后注入错误，再验证继续输入及 IME/长文本尾部可见。
- 历史向量记忆设置只编辑角色卡草稿，清空请求在 viewport 回调之后交给 roleplay；清空须选中当前编辑角色的确认项且当前任务空闲，角色切换须清除确认。清空当前角色后排队重开会话，避免继续使用已删除的召回背景；不清除固定记忆。
- 长期记忆默认本地开启，界面提供本地/远程选择；本地只展示模型与 CPU 线程控制，不能要求地址或 Key。切换来源保留另一模式的草稿字段，保存才生效；已有关闭配置不自动开启，关闭不删除历史数据。
- 人物记忆只在成功聊天后排队，任务绑定来源角色和连接快照；连接改变丢弃旧队列并中止旧任务。人物记忆入口与设置平级，浏览状态不得放入 RoleEditor，关闭设置不能重置记忆窗口；无提炼开关或说明文案。后台 Client 的提炼文本、错误和状态只能写独立服务内部状态，不得写聊天文本、历史、输入、busy 或普通 codex_status。浏览不调用模型，删除在 viewport 回调后执行；Wife::from_root 不启动后台提炼，避免测试调用真实模型。
- 新建角色入口即使资源库为空也须可用，未导入立绘不能创建；选择器/导入工作在后台，启动操作在 viewport 回调后处理。创建任务由 Wife 单独持有，关闭设置不得中断已提交创建；完成后刷新列表，已有角色及聊天保持，用户主动切换时沿用既有会话切换。
- Live2D 的纹理和单调时钟由 Picture 持有；部位点击不能重建模型或重启待机，拖动不触发局部动作。模型自带根摇摆时不叠加桌宠正弦悬浮；点击先逆悬停变换再交给模型热区，原生输入范围仍只包含当前 alpha/可见控件。

- 主透明窗口最终输出在纹理采样/混合后统一转换到桌面 gamma 预乘表示，保持 alpha，不能裁掉素材边缘掩盖白边；独立原生 viewport 不重复转换。最终 pass 不注册输入区域，GL 资源在 on_exit 的当前上下文内销毁；GPU 验证用隐藏上下文和固定像素，不读取用户配置或发模型请求。

- texts 预设台词只作无 AI 输出时的回退：生成等待期间和当前轮次已有非空 codex_messages 时，即使气泡关闭/自动隐藏，也不能再次随机显示预设台词；不要仅凭可见 text 为空判断。AI 气泡显示全文/关闭操作保持，测试用模拟服务验证。

- 立绘交互回归显式选定换装，不能依赖素材库第一项；增加模型时检查原有换装和新增换装的屏幕逆变换、部位点击及拖动不触发动作。

- development 窗口位于 ui/development.rs，工作区/任务/提示领域位于平级 development；原生 viewport 不套用主窗穿透或透明 pass。切换项目和旧任务只在空闲执行；点击兼容的任务即切换发送目标并恢复线程，重复点击当前任务不重建会话。草稿按项目保留；运行中或不兼容的任务仅供浏览并提示原因，发送目标须显示。运行中先保存记录，完成/失败/中断后立即保存；跨项目与跨模式不得复用线程。

- development 的左右任务区须使用有界高度的容器；horizontal 内的竖向 separator 会占满父区剩余高度，不能让它把底部输入框挤出 viewport。原生验收需实际点击编辑框并发送，不能仅检查窗口已映射。
- development 执行记录的 CollapsingHeader 会强制 Extend，长命令须先按可用宽度减去缩进/按钮边距生成 Truncate galley，再作为标题；完整命令通过悬停展示。仅设置外层纵向 ScrollArea 不能防止横向撑宽。
- development 输入采用 Enter 发送、Ctrl+Enter 换行；发送键必须在 TextEdit 消费事件前处理，并使用固定编辑器 ID 校验焦点，换行交给 TextEdit::return_key 保留光标/选区语义；绘制编辑器后再查询 key_pressed 可能已被 TextEdit 吞掉。

- development 项目选择器在工作线程调用，UI 回调后启动并通过通道接收；取消不切换，运行中收到的目录须保留至空闲再切换。任务窗口使用 Normal 层级，防止 AlwaysOnTop 遮挡原生文件选择器；选择结果即使窗口已关闭也继续消费。

- 主应用类型为 Wife。development 的诊断只同步快照，不自动发送模型任务；页内操作在 viewport 回调后应用。项目记忆、诊断与登记测试仅 developmentMode 开启时附加，原始用户输入保持首个协议文本块。
- 测试与模型任务共用 busy/Client，结果按项目/run ID 回填；独立测试不得写入普通聊天、人物记忆或角色向量历史。中断、退出、角色重建都须结束测试并清队列；保存测试/项目记忆失败保留旧数据。

- 小窗口里的任务详情 ScrollArea 须显式 min_scrolled_height(0)：egui 默认 64px 的最小滚动高度会覆盖更小的 max_height，导致新增页签后仍把发送区挤出窗口。

- 中文输入回归须覆盖没有 Enabled/Preedit 的连续多次 Commit；单次完整预编辑序列不能发现 egui 0.31 首词后丢字的问题。共用兼容回调在 style::install 注册，按 viewport/聚焦控件隔离组合状态；主聊天与 development 均使用该回调，不分别拼接候选文本。

- Codex 生成期间输出气泡不因超时或外部点击关闭；无正文时只绘制等待提示，不把提示写入聊天内容。两次立绘短按收起输出及输入/思考区，再单击恢复累计输出，Live2D 部位动作保持。turn_ui_hidden 只控制显示，不能中断任务或丢弃 codex_messages/项目记录；流式片段不得重置点击计数或重开面板，完成保留显式收起，新发送/新会话重置。

- 设置和人物记忆共用 style::panel_style/card；样式只写当前 Ui，避免覆盖主桌宠和其他 viewport 的主题。人物记忆的标题/筛选固定，只有列表滚动；低于 400px 的可用高度使用紧凑工具栏并隐藏副标题，最小 400×300 下仍须露出首条卡片。调整设置几何时同步 settings-smoke 的命中坐标。

- 回复显示归属必须按发送来源判断，不能用 developmentMode 或开发窗口是否打开代替。开发窗口输入、诊断分析、测试失败分析显式使用 MessageSource::Development；只更新项目回复，不更新主窗 text/codex_messages 或思考提示，不清主窗草稿。development_turn 在完成/失败/关闭开发窗口后仍保留，下一次发送或会话重建才更新，避免尾部事件重新弹到主窗。

- Codex UI 消费须保留单帧事件数/时间预算并请求下一帧，合并流式片段后按批遮蔽；终态/审批等非流事件前须先处理组装后的凭据，不能只依赖逐片段遮蔽。development 运行中快照后台串行写入，后续更改保留 dirty，强制保存先等待旧快照，避免其覆盖最终状态。长代码、命令输出和 diff 使用限高 `show_rows`，仅裁剪绘制不能避免全文布局开销。

- 开发窗口运行中补充使用独立确认状态并绑定项目/任务/轮次；收到成功 ACK 才记入 supplements，确认期间用户继续修改的草稿不得被清除。失败、断连及重启保留草稿；任务先完成、ACK 后到达也不能将补充记到后来任务。输出的右键“复制”只取当前选区，不回退整段；使用只读 TextBuffer 保留选区/键盘复制，右键需恢复原选区，字符索引不能按 UTF-8 字节切片。代码/diff 继续按可见行段虚拟化，滚动更换行段时必须隔离选区 ID。

- development 的多进程协议夹具在并发测试下可能出现临时脚本 ETXTBSY；这组用例可用 `cargo test --locked ui::development::tests:: -- --test-threads=1` 串行验证，避免将夹具启动竞争误判为协议功能失败。

- 任务详情的末尾定位只在打开/重新点击/切换目标或重返任务页时执行，使用项目路径 + 任务 ID 区分目标；按真实布局滚动到末尾，不能每帧强制滚动干扰上翻阅读和选区复制。详情和代码/输出内部滚动区用 stick_to_bottom(true)，底部随新输出跟随，手动上翻暂停，回到底部恢复。

- 多个 immediate viewport 在主线程同步渲染/交换缓冲；禁止用逐 surface 的 vsync 作为动画时钟。主窗使用不依赖焦点的定时重绘，egui 0.31 的 request_repaint_after 会扣除 predicted_dt，软件限帧须补回该值，避免关闭 vsync 后空闲忙循环。

- 备忘录使用独立 MemoUi 和原生 viewport，数据仅在首次打开时加载；from_root 不访问用户备忘录。事项操作在 viewport 回调后执行，成功落盘才更新勾选/删除状态和清空新增草稿；关闭保留未添加草稿。多行编辑器须限高滚动，事项预留删除按钮宽度并显式 Wrap，避免长文挤出控件。
