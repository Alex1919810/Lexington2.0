# 头发共享待机与保形摆动

适用于给现有统一角色增加头发飘动、加大摆幅或修复发丝扭曲。沿用共同原画、呼吸和根摇摆，不为每个动作重新画一套头发。只修改当前需要的发束；靠近身体、缺少隐藏纹理的短发束可以保持稳定。

## 方法选择与已验证的失败

本次直接放大合成图的局部位移场后，细发丝出现可见折弯。即使位移场的 Jacobian 行列式为正，局部仍可明显压缩或剪切；“不翻折”不足以证明保形。距离遮罩、模糊与更多插值迭代也不能补救错误的运动方式。

对于需要保留原画弧线的小幅摆动，优先提取独立发束层，以发根附近的局部轴做 scale=1 的整体旋转。身体、手臂和花束通过绘制顺序与遮挡层覆盖头发，不把它们的逐像素保护权重乘进发束位移。后者会在保护区旁生成挤压，增幅后尤其明显。

这不是禁止网格。若需要分束错相或发梢弯曲，可在已正确分层的发束上增加受约束网格/骨骼，限制长度、宽度、剪切和曲率变化。保持整体旋转是保守起点，不宣称它已经实现完整发丝物理。增加幅度时先复查静态极值、轮廓和接缝，再渲染整段。

## 从原画提取发束

- 在浅底、深底和透明底查看源发束层，包含细外轮廓，排除脸、颈部、肩、蝴蝶结、花束与裙装蕾丝。多边形和 alpha 连通分量可辅助，但相邻装饰可能接触头发，不能直接把最大连通区域当作语义分割。
- 发梢附近的裙装特别容易误入切图；标定真实发梢终点和内侧轮廓。颜色筛选也需查看结果，不能把浅色/偏紫的头发打成孔洞，或一律复制案例的高度阈值。
- 独立发束不要再次跟随躯干呼吸网格拉伸。保护范围来自实际发束像素；空白包围盒、误入的蕾丝经过膨胀/模糊后，可能连带改变更远处的裙摆。
- 不强迫缺少背面纹理的所有发束一起移动。先选择素材可支持的部分和幅度，再决定是否补图；大幅摆动需先补齐并检查隐藏内容。

## 发根、内侧切口与透明度

旋转后的发束应位于正确的头部/躯干遮挡层后方，原画发根作为稳定覆盖。不要在整张原图与一张重组姿态间切换来掩盖接缝。

若内侧切口在摆动时露缝，可在**被身体遮住的内侧**保留少量纹理余量。只覆盖当前小幅动作需要的隐藏范围，沿接缝平滑收束；突然停止会形成方形缺口或突起。原纹理外延只是一种局部近似，不能称为恢复完整隐藏头发，也不能扩张自由发梢的外轮廓。

半透明素材拆层后直接 alpha-over 可能变色、变厚。对源 alpha 为 A、源颜色 C、提取权重为 m 的重叠区域，可用以下同色分层作为中性姿态的参考：

```text
发束 alpha F = A*m
静态层 alpha B = A*(1-m)/(1-A*m)
两层颜色均为 C；在预乘 alpha 中变换、合成。
```

分母为0时按透明静态层处理。上式只说明原内容的拆分；补出的纹理余量仍必须被正确遮挡。半透明衣服不能自动视作不透明挡板，需检查原有颜色与 alpha 是否被改变。

只在角度恰好为0时返回原图，不足以证明分层正确：还要比较接近0的正负角度、起步和回位，避免刚开始运动便跳边或变色。导出普通 PNG/WebP 前反预乘；透明像素不得携带重采样白晕。

## 时钟与统一动作

头发的持续飘动读取共享 global_time，眨眼和抬花只更新自己的局部通道。先计算发束局部角度，再合成当前前景，最后施加一次全局根变换。点击时不重启头发，也不要在新动作 GIF 中单独重设相位。

头发周期、角度、轴心与相位都是当前模型的数据。发根轴随头部骨骼运动；有多发束时可以错相，但应保持同一个全局时间来源。若展示版承诺相同首尾，选择共同循环周期并验证实际编码结果，而非复制末帧或重启时钟。

## 验收与交付

1. 先比较原画与 neutral、两侧极值、中间姿态；放大发根、最长发梢、细丝和内侧接缝。检查实际源层是否混入服装，再看数学指标。
2. 分别检查头发、呼吸、根摇摆及组合效果。验证非目标的脸、手臂、花束和下方裙摆；采样矩形由当前图像标定。头发保护遮罩不能使原有呼吸消失。
3. 在非整周期时刻触发局部动作并叠加，检查头发相位连续；动作归位应匹配同一全局时刻的待机。不同前景遮挡造成的可见覆盖变化，不等于时钟应重置。
4. 查看实际 GIF/视频的正常速度、慢放与局部放大。检查轮廓挤压、剪切、断裂、双边缘和肤色闪烁；刚性变换的单位尺度不能替代这些检查。少量预检通过后再导出整套，编码后再核对循环与同步。
5. 保存发束源纹理、精确遮罩、轴心/坐标约定、角度函数、图层顺序与遮挡方法。仅有预览或矩阵参数不够重现切图合成；参考渲染器需随包验证，仍区分素材预览与真实应用接入。

## 中位停顿与帽发交界

- 用户说“卡顿”时先区分掉帧与动作暂停。持续往返若共用躯干的 `sin³(phase)`，经过中位时速度也为零；需要连续摆动时使用独立 `amplitude*sin(phase)`，保留全局时钟、周期和端点减速。检查中位前后连续几帧的位移，而非先提高 FPS 或改变摆幅。
- 恢复原画发色前，先排除完整手臂和静态身体的所有权。旧发区遮罩可能含一块肤色或泳装，移动后才显成白块。隐藏臂后的发区使用补齐的发纹理，RGB 在已确认的发区内平滑衔接；不能把旧手臂颜色或手臂形状的空洞一起复制回来。
- 头部冠发、固定发根、自由背发分别管理。完整冠发留在头部层；不能沿帽子放下时的接触线裁掉抬帽后需要露出的头发，也不能将生成的整块头皮塞入摇摆背发。固定根层沿真实后脑轮廓覆盖太阳穴，并与移动发束重叠；只在 neutral 帽沿高度水平截断，会在抬帽后露出矩形缺口。
- 帽子的前后归属使用连续几何深度区域，与帽网透明孔、补发 alpha 分离。完整后帽沿在头部/固定发根之后，完整前帽沿在其前；对两套完整合成结果插值，不分别裁切、重采样半透明边再叠加。点击遮挡与同一顺序一致。帽发接触带的原画混色像素不能贴到移动帽上，优先保留连续帽纹理；局部纹理余量和头侧支撑只覆盖实际动作需要的范围。
- 补发检查必须含帽子静止、中间、最大抬升以及头发两侧极值的叠加。查看冠部是否虚高、花心/手指是否被颜色阈值挖空、帽沿是否压入固定发根；骨长、三角形面积或单点 alpha 通过均不能替代放大画面。
