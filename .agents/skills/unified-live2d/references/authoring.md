# 原画到统一角色

## 基准先于动作

查看输入 PNG 的实际尺寸、透明度和眼睛/手指的原始像素数；建立 neutral.png，固定人物尺度、画布、脚底锚点、头部角度和颜色。所有动作使用同一组图层和坐标，不为每个动作重新生成整个角色。

可以从现有认可版本提取共同基准；不要继续叠加此前被用户否定的拉伸、补片或错误关键帧。用户认可的是动作的某个部分时，保留该部分，而不是把整条历史输出视为认可。

## 分层与补图

按当前需要分出躯干/头发、左右上臂、前臂、持物、眼部局部层和遮挡层。单 PNG 只提供可见像素：动作揭开手臂后原被挡住的衣服、头发与皮肤，需要清理底板或原画补图。AI 输出仅用于需要的局部或姿态参考，不替换已经正确的脸和衣服。

局部生成提示词可沿用这个结构：

> 以输入立绘为编辑目标，保持身份、画风、身体比例、头部角度、画布尺寸和底部锚点。只完成指定部位的局部动作/补图，保留原有手臂粗细、关节和持物大小。不改变躯干长度、胸腰位置或其他服装细节；保持真实 alpha；不添加文字、背景或额外手指。新露出部分与原图结构连续。

请求画布、透明背景或保持比例不等于工具实际做到：检查文件尺寸、alpha 和背景光晕。生成图比例不同时不可硬拉伸成目标尺寸。先统一尺度/位置，再对需要的局部配准，最终仅合成经过检查的区域。

透明素材在预乘 alpha 中变换，预乘工作缓冲的颜色范围满足 `0≤RGB≤255×alpha`，透明像素 RGB 为0。保存普通 straight-alpha PNG/WebP 前需反预乘，避免重复乘 alpha 使边缘变黑。配准可用固定中性底色观察透明边缘，但不能把该底色烘进透明输出；半透明参考的几何重采样也应预乘后进行。

## 手部保形

- 使用原图手臂的可见纹理和 alpha 轮廓，先检查 cutout 是否混入头发、衣服或背景。不以宽多边形外框代替实际胳膊边缘。
- 上臂与前臂按骨段旋转，持物跟随腕部；固定骨长、原画粗细与稳定弯肘方向。固定关节遮挡层必须来自原画，不能新增一大块肩部皮肤掩盖接缝。
- 一套持续使用的重组图层贯穿待机和动作。不要在“原始整图”与“分层合成结果”间切换，或把两套胳膊整图淡化叠在一起；这会造成突然变粗、双边缘和接缝跳变。
- 用较小动作检查中间姿态；缺少上臂隐藏段时，允许的动作幅度由素材决定。若大幅动作必需，先补齐并验证图层，不能用简单圆柱、圆形补片或整体躯干拉伸顶替。
- 逆运动学每条手臂选固定 pole（弯曲侧），不可每帧从原肘与当前腕线的叉积重选。接近伸直时解对目标位移有平方根敏感性，可提高目标端缓动阶数或保留弯曲余量；不要仅把轨迹采样加密就称为消除跳变。

## 头发保形

需要飘动、增幅或修复头发扭曲时，读取 [hair.md](hair.md)。先检查原画发束的独立图层与根部遮挡，再选择整体摆动或受约束网格；不要把已出现挤压的合成图位移场继续放大。发梢旁的蕾丝、蝴蝶结、花束和肤色像素也要从切图中排除。

## 共享待机与动作

呼吸、摇摆和持续头发飘动只读全局单调时钟；眼睑、手部等动作读取各自起始时刻。先合成本地部位姿态，之后仅施加一次全局根变换。呼吸可以是躯干网格参数，独立发束、手臂和持物不跟着被拉宽。

原生分层渲染时对躯干层应用呼吸，对臂与持物保留刚性变换；离线合成图上做呼吸时保护这些前景像素并让场在边界平滑衰减。头部整体移动时眼部跟随头部层，不要将固定眼睛补丁贴到已摇动的成图上。

以局部动作参数归位作为常态衔接。展示版若要求首末画面完全相同，选择共用周期与相位，并让末段回 neutral；不要在运行中为了回到 GIF 首帧而重启全局呼吸。用固定调色板导出整套 GIF，否则相同 RGBA 基准仍可能被编码成不同肤色。

## 交付层级

素材阶段：neutral、共享图层/图集、动作轨道、热区、坐标与合成顺序。预览阶段：并排动作以及在非周期边界模拟触发的连续视频。运行阶段：在用户指定应用中实现时钟、状态控制、热区和渲染，并做实际交互验收。

明确交付到了哪一层。素材包与模拟点击视频不代表实时点击已经实现，也不自动成为 Cubism 格式。具体角色的速度、周期、像素幅度、坐标与颜色阈值都是模型数据；不要升级成所有角色的固定要求。

## 完整图层、边缘与原画恢复

单张立绘缺少隐藏臂、帽、板身或发根时，先补完整部件并配准，再验收 neutral / 中间 / 极值。生成图的请求尺寸、实际画布和物体比例可能不同；配准后仍需核对源层是否混入其他部位。整条手臂可用共享顶点的连续蒙皮和固定分支 IK；生成连续表面上硬贴旧皮肤或板身切片，常把原遮挡边界变成内部色缝。共享三角形边界不能反复 alpha-over。

保留原脸时要核对轮廓 RGBA，而非只把原脸 alpha-over 到新脸上；后者会加厚下颌抗锯齿。胸腰的原画半透明边缘也不能叠在更宽的不透明生成底板上；原画后方是其他物件时，源 alpha 可能全不透明，需要先确认真实身体轮廓和背景混色。公开运行资源应是审核过的完整分层结果，而非制作过程中不断累加的补片。

缩小透明层先预乘 alpha。细边若出现游离低 alpha 色点，检查 Lanczos 等负瓣滤波的振铃及反预乘后的极端 RGB；可改用正权面积滤波，再看浅、深底实图。不要用全轮廓开运算或硬阈值磨掉细发、帽网来掩盖问题。明确不透明的生成材料内部若带近不透明 matte，需与真实轮廓覆盖率区分，不能整层随意抬高 alpha。
