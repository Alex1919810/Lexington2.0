# 已验证的问题与验收

## 常见失真

| 问题 | 原因 | 修正 |
| --- | --- | --- |
| 花束上移但躯干变长 | 用整块腰部网格替代臂动作 | 固定身体结构，分出臂与物件，按肩肘腕驱动 |
| 胳膊突然跳到另一侧 | 近伸直 IK 每帧重选弯曲侧 | 每臂固定 pole；检查整个参数范围与接近伸直的速度 |
| 手臂明显变粗、轮廓不同 | 补画圆柱、过大肩部补片、截入衣服背景 | 使用原画纹理/alpha，检查分割；缺图先补齐审核或减小幅度 |
| 起步/回位胳膊双边缘 | 原始整图与分层姿态交叉淡化 | 始终用同一套重组图层；过渡角度、腕目标和权重 |
| 呼吸把手臂/花束拉宽 | 呼吸场作用于整幅合成图 | 按躯干层驱动，或离线保护前景像素，场在边界衰减 |
| 修手臂后呼吸没了 | 局部修正重置了整套状态 | 共享 idle 与局部动作分离，用户保留项明确验收 |
| 切换动作身体摇摆重启 | 每个 GIF 烘焙自己的时钟 | 共用全局 idle；局部动作不拥有根位移 |
| 首末姿态相同但肤色闪 | GIF 单独量化调色板 | 整套共享 palette，比较实际解码首末帧与 neutral |
| PNG正常、透明预览有底色 | 先混预览底色再恢复 alpha | straight RGB 做参考，预乘 alpha 变换，仅最后预览合底色 |
| 热区与角色错位 | 用屏幕坐标或旧姿态热点 | 逆根变换，再测当前局部/骨骼形状 |
| 头发增幅后出现折弯、挤瘪 | 放大带局部保护遮罩的位移场，细发丝附近梯度过大 | 原画发束独立分层后保形摆动；遮挡通过合成处理，不在每个像素上截断位移 |
| 发梢带着蕾丝移动、接缝出现直角 | 切图混入裙装，或内侧纹理余量突然截断 | 查源图层与实际 alpha；收紧语义边界，隐藏接缝的纹理余量平滑收束 |

眼部专属问题见 [eyes.md](eyes.md)，头发专属问题见 [hair.md](hair.md)。动作幅度、颜色阈值、每帧像素位移应按模型尺寸和画风判断，不把案例的10像素或某个帧步长变成所有角色的阈值。

## 必查证据

- 先对比原画与 neutral / 中间 / 极值姿态：骨段和持物无意外缩放，补图不变脸、不增粗、不拉长躯干。检查每段手臂 alpha 轮廓而不只看关节点。
- 检查连续帧的肘部/腕部轨迹，尤其 near-straight、开始、回位及 pole 分支附近；数学轨迹顺不代表切图边缘不跳。
- 发束放大看原始弧线、宽度、发根及内侧切分线。`det(J)>0` 只排除局部翻折，不排除可见挤压；刚性矩阵 scale=1 也不证明切图、遮挡或采样边缘正确。先用少量极值/过渡帧检查脸、手臂、花束和下方裙摆，再重导整套动画。
- 呼吸单独开启时验证臂与持物没有被拉宽；关闭眼部通道时确认全程睁眼。只渲染用户要求的动作组合。
- 在非 idle 周期边界模拟触发；开始与结束应匹配该全局时刻的 idle。不同通道叠加不互相清零，同通道的排队或打断策略明确。
- 检查原始 RGBA、中性底/浅底/深底合成和实际 GIF；透明像素残留 RGB、不正确的预乘范围、反复缩放与颜色量化都可能制造新缺口。
- 同周期对比 idle 与眼部动作，眼部 ROI 之外应一致；持物动作与 idle 的头部应共用同一根变换。区域坐标由当前模型标定。
- 展示版若承诺同首尾，以解码后的固定调色板 GIF / 无损帧检查；透明像素隐藏 RGB 应规范化后比较。H.264 压缩像素差异不能直接当作姿态不一致。
- 核对真实 fps、总时长、保持帧合并与关键动作区间。重复保持帧合法，不以“所有帧都必须不同”验收。GIF常用30fps并按10ms累计量化；60fps用视频或WebP。
- 最后看整段正常速度、慢放和肩肘/眼部放大。素材包、预览模拟、真正可点击的应用分别标明，不能仅因 JSON 或脚本检查通过就宣称交互完成。
