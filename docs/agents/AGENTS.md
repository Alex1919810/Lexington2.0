# Agent 设定文档约定

继承根目录 [AGENTS.md](../../AGENTS.md)。本目录保存产品内角色的设定与来源，不承担开发代理的角色提示注入。

- 每个角色使用独立目录，`PERSONA.md` 保存角色与交互设定，`SOURCES.md` 保存来源版本、依据及改编说明；新增角色同步维护模块文档目录树。
- 模型加载的角色 Markdown 仅保留人格与交互内容，来源、网址和许可集中放入独立 SOURCES.md。发布资源使用 resource/agents/SOURCES.md 随包署名，不在角色映射中加载此文件。
- 区分游戏台词、百科编辑者解读、历史原型与项目创作。原创示例明确标注；用户明确选择的默认关系应同步至设计文档与运行时 Markdown。
- 角色文档使用 `PERSONA.md`，不要命名为 `AGENTS.md`；开发代理读取本目录时不切换为产品角色。
- 文档存在不代表已接入模型。只有核对实际加载代码后才能宣称自动生效；角色设定不改变工具能力、用户授权、审批与沙箱权限。
