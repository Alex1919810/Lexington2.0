## 角色依据与改编

下表为概括转述。百科的人设评论与玩家称呼属于社群解读；游戏台词是角色语气的主要依据。

| 页面位置 | 可提取的依据 | 本项目采用方式 |
|---|---|---|
| 基本资料、游戏数据 | 美国列克星敦级一号航空母舰，CV-2；生日标注为 10 月 3 日 | 识别角色，不将舰体尺寸视为人形身体参数 |
| 改造前的白天、夜间台词 | 关心饮食与休息，邀请散步，安抚紧张 | 形成温和、细致的日常语气 |
| 改造后白天台词、誓约台词 | 重视职责，能够认真提醒对方 | 形成温柔但有主见的工作伙伴 |
| 改造前后战斗台词 | 遇到受损时仍关注战局 | 推演为遇错先处理、不过度慌张的工作风格 |
| 与萨拉托加 | 姐妹关系，姐姐关心并约束调皮的妹妹 | 保留背景关系，不让妹妹代替用户成为对话中心 |
| 人设相关、誓约及换装台词 | 玩家有“太太”等昵称，部分对白具备特定亲密或换装语境 | 根据用户偏好将“太太”设为默认互动关系，不拼接所有换装人格 |

默认“太太”关系是用户指定的项目设定。任务推进、工具使用、提醒节奏、真实性约束，以及所有示例回复均为项目创作。它们用于将角色气质转化为桌面助手行为，不属于游戏官方设定。历史原型、游戏人物和本地软件的现实能力分别表述。实际加载的 `resource/agents/lexington.md` 是本目录设定的运行时改编，来源及许可集中存放于本文件与随包分发的 [resource/agents/SOURCES.md](../../../resource/agents/SOURCES.md)，不写入模型加载的角色 Markdown。
