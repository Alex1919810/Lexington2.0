# 对话框文本系统实现

## 功能需求

1. 从 `resource/texts` 目录读取文本文件（格式为 JSON 数组）
2. 根据当前显示的角色（文件夹名）加载对应的文本列表
3. 点击立绘时，随机从当前角色的文本中挑选一条显示

## 实现方案

### 1. Electron 后端实现

#### 1.1 在 `fileScanner.js` 中添加读取文本函数

- 添加 `loadCharacterText(characterName)` 函数
- 读取 `resource/texts/{characterName}/text.json` 文件
- 解析 JSON 并返回文本数组
- 处理文件不存在或格式错误的情况

#### 1.2 在 `ipcHandlers.js` 中注册 IPC 处理器

- 添加 `load-character-text` IPC 处理器
- 调用 `fileScanner.js` 中的读取函数

#### 1.3 在 `preload.js` 中暴露 API

- 添加 `loadCharacterText(characterName)` 方法到 `electronAPI`

### 2. 前端实现

#### 2.1 在 `App.vue` 中添加文本管理逻辑

- 添加 `currentCharacterTexts` 状态存储当前角色的文本列表
- 添加 `loadCharacterTexts(characterName)` 函数，调用 Electron API 加载文本
- 添加 `getRandomDialogText()` 函数，从当前文本列表中随机选择一条
- 修改 `dialogText` 的初始化，改为空字符串（初始不显示）
- 监听 `currentCharacter` 变化，自动加载对应角色的文本

#### 2.2 在 `VisualWifi.vue` 中修改点击逻辑

- 修改 `handleDialogClick()` 函数
- 点击时从父组件获取随机文本（通过 emit 事件或 prop 传递）
- 或者直接在 `App.vue` 中处理点击事件，更新 `dialogText`

## 文件修改清单

1. **electron/fileScanner.js**

   - 添加 `loadCharacterText` 函数

2. **electron/ipcHandlers.js**

   - 添加 `load-character-text` IPC 处理器

3. **electron/preload.js**

   - 添加 `loadCharacterText` API

4. **src/App.vue**

   - 添加文本管理状态和函数
   - 监听角色变化并加载文本
   - 提供获取随机文本的方法

5. **src/components/VisualWifi.vue**

   - 修改点击处理逻辑，从父组件获取随机文本

## 数据流

```
用户点击立绘
  ↓
VisualWifi.vue 检测到点击
  ↓
通知 App.vue（通过 emit 或直接调用方法）
  ↓
App.vue 调用 getRandomDialogText()
  ↓
从 currentCharacterTexts 中随机选择一条
  ↓
更新 dialogText prop
  ↓
DialogBubble.vue 显示文本
```

## 注意事项

1. 文本文件格式：JSON 数组，如 `["文本1", "文本2", "文本3"]`
2. 角色名匹配：文件夹名（如 `lexington`）需要与立绘的角色名（`character` 字段）匹配
3. 错误处理：如果角色没有文本文件或文件格式错误，应优雅处理（不显示对话框或显示默认文本）
4. 文本加载时机：在角色切换时自动加载，避免重复加载
5. 随机选择：确保每次点击都能随机选择，避免连续显示相同文本
