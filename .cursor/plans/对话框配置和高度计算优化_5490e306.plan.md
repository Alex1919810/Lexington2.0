# 对话框配置和高度计算优化

## 目标

1. 创建 `config/config.json` 作为项目配置文件
2. 添加对话框固定宽度和最大高度的配置项
3. 在对话框显示前计算所需高度，避免打字机效果过程中高度变化

## 实现步骤

### 1. 创建配置文件

在 `config/config.json` 中定义对话框配置：

- `dialog.width`: 固定宽度（像素）
- `dialog.maxHeight`: 最大高度（像素）

### 2. 主进程添加配置读取 API

在 `electron/main.js` 中：

- 添加 IPC 处理 `get-config`，读取并返回 `config/config.json` 内容
- 如果配置文件不存在，返回默认配置
- 使用 `fs.readFileSync` 读取 JSON 文件

### 3. 预加载脚本暴露配置 API

在 `electron/preload.js` 中：

- 在 `electronAPI` 对象中添加 `getConfig()` 方法
- 调用主进程的 `get-config` IPC

### 4. 修改 DialogBubble 组件

在 `src/components/DialogBubble.vue` 中：

#### 4.1 配置读取

- 在 `onMounted` 中调用 `window.electronAPI.getConfig()` 读取配置
- 存储对话框宽度和最大高度到响应式变量

#### 4.2 高度计算逻辑

- 添加响应式变量 `calculatedHeight` 存储计算出的高度
- 创建隐藏的测量元素（使用相同的样式）用于计算文本高度
- 在 `watch(() => props.visible)` 中，当 `visible` 变为 `true` 时：
- 使用完整文本（`props.text`）计算所需高度
- 考虑固定宽度、padding、line-height、字体大小
- 如果计算高度 <= 最大高度：使用计算高度
- 如果计算高度 > 最大高度：使用最大高度，启用滚动

#### 4.3 样式应用

- 修改 `.dialog-bubble` 样式：使用配置的固定宽度，移除 `width: fit-content`
- 修改 `.dialog-content` 样式：使用 `calculatedHeight` 作为高度（通过 `:style` 绑定）
- 确保 `overflow-y: auto` 在超过最大高度时生效

#### 4.4 打字机效果优化

- 保持打字机效果逻辑不变
- 确保 `calculatedHeight` 在打字机过程中不变（只在显示前计算一次）

## 技术细节

### 高度计算方法

使用隐藏的测量元素：

1. 创建临时 DOM 元素，应用相同的样式（宽度、padding、字体、行高）
2. 设置文本内容为完整文本
3. 测量 `scrollHeight` 或 `offsetHeight`
4. 清理临时元素

### 配置默认值

如果配置文件不存在或读取失败，使用默认值：

- `dialog.width`: 200px
- `dialog.maxHeight`: 120px
